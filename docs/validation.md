## 复现方式

默认 `mvn verify` 运行本地单元测试和 SQLite 验收。指定以下 JVM 属性，可加入 PostgreSQL、MySQL 和真实 Redis 检查：

```text
astra.test.postgresql.url=jdbc:postgresql://127.0.0.1:5432/astra_acceptance
astra.test.postgresql.user=postgres
astra.test.postgresql.password=你的测试密码
astra.test.mysql.url=jdbc:mysql://127.0.0.1:3306/astra_acceptance
astra.test.mysql.user=root
astra.test.mysql.password=你的测试密码
astra.test.redisExecutable=独立 redis-server 可执行文件路径
```

URL 必须指向专用测试数据库。测试只创建新框架表，没有旧表迁移。真实 Redis 检查自行启动和结束临时进程；未提供可执行文件时会显式跳过，跳过的检查不计为已验证。CI 为这三种服务配置独立测试环境。构建输出位置见 [构建与发布](deployment.md#构建与发布)。
